## Dataset

`github_gold.csv` is an unmodified copy of *A gold standard for polarity of
emotions of software developers in GitHub* by Nicole Novielli, Fabio Calefato,
Davide Dongiovanni, Daniela Girardi, and Filippo Lanubile.

- Source and citation: https://doi.org/10.6084/m9.figshare.11604597
- License: https://creativecommons.org/licenses/by/4.0/
- Associated paper: https://doi.org/10.1145/3379597.3387446

The training process replaces URLs, code blocks, commit hashes, and repeated
whitespace in memory. It does not modify the CSV stored in this directory.

See [`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) for the complete
attribution notice.
